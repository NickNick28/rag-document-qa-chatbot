หน้านี้สรุปแนวทางใช้งานระบบอย่างปลอดภัย เหมาะสำหรับผู้ใช้ทั่วไปและผู้ดูแลบอท

## 1) เอกสารที่ควรหลีกเลี่ยง
- เอกสารที่มีข้อมูลส่วนบุคคลจำนวนมาก (เช่น เลขบัตรประชาชน, ที่อยู่, ข้อมูลสุขภาพ)
- ข้อมูลลับภายในที่ไม่ควรเผยแพร่

## 2) การตั้งค่าสิทธิ์ (Explore/Guest)
- เปิด **Explore** เฉพาะบอทที่เหมาะสำหรับใช้งานร่วมกัน
- เปิด **Guest** เฉพาะเมื่อจำเป็น และปิดทันทีหลังใช้งานเสร็จ

## 3) ขอบเขตความถูกต้อง
- คำตอบขึ้นกับ “เอกสารที่อัปโหลด” เป็นหลัก
- หากเอกสารเก่า/ไม่อัปเดต คำตอบอาจไม่ตรงกับประกาศล่าสุด

<Callout type="warning" title="ข้อควรระวัง">
  หากมีการเปลี่ยนแปลงประกาศ/ระเบียบ ควรอัปโหลดเอกสารเวอร์ชันล่าสุด และลบ/ปิดการแชร์เวอร์ชันเก่า
</Callout>


## การเผยแพร่บอท (Explore / ลิงก์)

- การเผยแพร่บอทไปหน้า **Explore** และการสร้าง **ลิงก์สำหรับผู้ใช้ภายนอก (Guest link)** ทำได้เฉพาะผู้ใช้กลุ่ม **Staff**
- ทุกครั้งที่ขอเผยแพร่ ระบบจะสร้าง **คำขออนุมัติ** และจะมีผลเมื่อ **Admin อนุมัติ** เท่านั้น
- หลีกเลี่ยงการอัปโหลดเอกสารที่มีข้อมูลอ่อนไหว หากมีความจำเป็นให้ปรึกษา Admin ก่อน
