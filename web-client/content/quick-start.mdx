หน้านี้ออกแบบให้ “เปิดมาแล้วทำตามได้เลย” เพื่อสร้างบอท 1 ตัว + อัปโหลดเอกสาร + เริ่มถามได้ทันที

## สิ่งที่ต้องมี
- บัญชี **@nu.ac.th**
- ไฟล์ PDF ที่ไม่เกิน **10MB** และไม่เกิน **10 หน้า/ไฟล์**

---

## ขั้นตอน (ทำตามได้เลย)

### Step 1: เข้า Overview แล้วสร้างบอทใหม่
- กด **สร้างบอทใหม่** (ปุ่มสีส้ม) หรือไอคอน **+**
- กรอก **Display Name** และ **Description**
- กด **Create Assistant**

![Create Assistant](/images/Create_Assistant.png)

### Step 1.1: ยืนยัน “สร้างแชทบอทสำเร็จ” และไปหน้าตั้งค่า
หลังจากสร้างสำเร็จ ระบบจะแสดงหน้าต่างยืนยัน
- กด **ตั้งค่าแชทบอท** → ไปหน้า Settings เพื่อเริ่มตั้งค่าทันที (แนะนำ)
- กด **เอาไว้ก่อน** → กลับไปหน้า Overview (สามารถกลับมาตั้งค่าภายหลังได้)

![Create Success Modal](/images/CreateSuccessModal.png)

<Callout type="info" title="แนะนำ">
  เพื่อให้ทำ Quick Start จบภายใน 5 นาที ให้กด “ตั้งค่าแชทบอท” แล้วไปต่อ Step 2 ได้เลย
</Callout>

### Step 2: ตั้งค่า System ให้ตอบ “นิ่งและแม่น”
ไปที่ **Settings → System**
- ใส่ System Instructions (ไม่บังคับ — แนะนำให้ใส่เพื่อให้ตอบนิ่งและแม่น)
- ตั้ง Temperature = **0.3-0.5**
- ใส่ Recommended Questions 3–5 ข้อ (ไม่บังคับ — ใส่เพื่อช่วยให้ผู้ใช้เริ่มถามง่ายขึ้น)

ตัวอย่าง System Instructions:
- “ตอบจากเอกสารในระบบเท่านั้น หากไม่พบข้อมูลให้แจ้งว่าไม่พบ และแนะนำคำถามเพิ่มเติม”
- “ตอบเป็นภาษาไทย หากมีตัวเลขให้แสดงเป็นตาราง”

![Settings System](/images/SettingsSystem.png)

### Step 3: อัปโหลดเอกสารเข้า Knowledge Base
ไปที่ **Settings → Documents**
- กดเพิ่มไฟล์ PDF
- รอจนไฟล์ปรากฏในรายการเอกสาร

![Upload KB](/images/UploadKB2.png)
![Upload KB success](/images/UploadKB4.png)

### Step 4: เข้า Chat แล้วลองถาม 3 คำถาม
แนะนำให้ลองถาม 1-3 คำถามดังตัวอย่างเพื่อเช็กระบบ
1. คำเพื่อเช็คว่าในระบบการอัปโหลดเอกสารเข้าฐานความรู้: “ตอนนี้ในระบบมีเอกสารอะไรบ้าง?”
2. ขอให้สรุปข้อมูลคร่าวๆว่าเอกสารดังกล่าวเกี่ยวกับอะไร: “ช่วยสรุปข้อมูลจากเอกสารที่อัปโหลดไปว่าเกี่ยวกับอะไร”
3. ถามนอกเอกสารหรือข้อมูลที่ไม่เกี่ยวข้องกับตัวเอกสาร: “ทุนการศึกษามีอะไรบ้าง?” → ควรตอบว่า “ไม่พบข้อมูลในเอกสาร”

![Chat](/images/chat3.png)
