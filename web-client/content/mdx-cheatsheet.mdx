หน้านี้รวบรวม Syntax และตัวอย่างการใช้งาน MDX/Markdown สำหรับเขียนคู่มือในระบบ Documentation (เช่น หัวข้อ, ตาราง, Callout, รูปภาพ)

> **แนะนำ:** ไม่ควรใช้ `#` (H1) ในเนื้อหา เพราะระบบใช้เป็นชื่อเรื่องของหน้าแล้ว

---

## 1) การจัดรูปแบบข้อความ (Text Formatting)

- **ตัวหนา**: `**ข้อความ**` → **ข้อความ**
- *ตัวเอียง*: `*ข้อความ*` → *ข้อความ*
- ~~ขีดฆ่า~~: `~~ข้อความ~~` → ~~ข้อความ~~
- `Inline Code`: `` `code` `` → `code`

---

## 2) หัวข้อ (Headings)

ระบบจะสร้างสารบัญด้านขวาอัตโนมัติจากหัวข้อเหล่านี้:

## หัวข้อหลัก (H2)
### หัวข้อย่อย (H3)
#### หัวข้อย่อยลงไปอีก (H4)

---

## 3) รายการ (List)

### Bullet list
- รายการที่ 1
- รายการที่ 2

### Numbered list
1. ขั้นตอนที่ 1
2. ขั้นตอนที่ 2

---

## 4) ตาราง (Markdown Table)

| รายการ | รายละเอียด |
|---|---|
| Display Name | ชื่อบอทที่ผู้ใช้เห็น |
| Description | คำอธิบายสั้น ๆ |

---

## 5) รูปภาพ (Image)

```md
![คำอธิบายรูป](/images/your-image.png)
```

**ทิป:** ชื่อรูปควรสื่อความหมาย เช่น `overview-dashboard.png`, `settings-system.png`

---

## 6) Callout / กล่องข้อความ (แนะนำใช้ในคู่มือ)

ตัวอย่าง:

```mdx
<Callout type="info" title="ทิป">
  เนื้อหาที่เป็นคำแนะนำหรือ Best practice
</Callout>
```

ประเภทที่แนะนำ:
- `info` : ข้อมูลเพิ่มเติม / คำแนะนำ
- `warning` : ข้อควรระวัง
- `success` : ผลลัพธ์ที่ควรได้ / ทำถูกต้องแล้ว
- `error` : ปัญหาและวิธีแก้ (ถ้าระบบรองรับ)
