หน้า Overview เป็นหน้าหลักสำหรับ “จัดการบอททั้งหมดของคุณ” และดูสรุปการใช้งาน

## ส่วนสรุปด้านบน (Dashboard Cards)

- **My Chatbots**: จำนวนบอทที่คุณสร้าง
- **Total Conversation**: จำนวน session การสนทนา
- **Token Usage (Monthly)**: การใช้งาน token รายเดือน (รีเซ็ตตามรอบที่ระบบกำหนด)

![Overview Cards](/images/OverviewCards1.png)

## รายการบอท (Bot Cards)

แต่ละบอทจะแสดง:
- ชื่อบอท / สถานะ (เช่น Private, Closed)
- วันที่ Created / Updated
- ปุ่มใช้งาน เช่น
  - **เริ่มแชท**
  - **ตั้งค่า (ฟันเฟือง)**
  - **ลบ (ถังขยะ)**

![Bot Cards](/images/BotCards.png)

## การค้นหาและฟิลเตอร์
- ช่องค้นหา: ค้นหาชื่อบอท
- ฟิลเตอร์เวลา: เช่น Recently Updated / All Time (ตามที่ระบบมี)

## สิ่งที่ควรทำในหน้านี้
- สร้างบอทใหม่
- เข้า Setting เพื่ออัปโหลดเอกสาร/ตั้งค่า Prompt
- ตรวจสอบว่าบอทอัปเดตล่าสุดเมื่อไร
