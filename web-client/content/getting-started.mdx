หน้านี้อธิบายภาพรวมการเริ่มใช้งานระบบตั้งแต่ **สร้างบอท → ตั้งค่า → อัปโหลดเอกสาร → เริ่มแชท**  
เหมาะสำหรับผู้ใช้ที่ต้องการเข้าใจ Flow การทำงานทั้งหมดก่อนใช้งานจริง

<Callout type="warning" title="ข้อจำกัดการสร้างบอท">
  ผู้ใช้ 1 บัญชีสามารถสร้างบอทได้สูงสุด <strong>2 บอท</strong> ต่อผู้ใช้
</Callout>

## การสร้าง Chatbot

หลังจากล็อกอินด้วยบัญชีมหาวิทยาลัยแล้ว ระบบจะพาผู้ใช้มาที่หน้า **Overview / Dashboard**  
ผู้ใช้สามารถสร้างบอทได้โดยกดปุ่ม **สร้างบอทใหม่** (ปุ่มสีส้ม) หรือไอคอน **+** ที่แถบด้านซ้าย

![หน้า Overview / Dashboard](/images/page_Overview.png)

<br />

เมื่อกดสร้างแล้ว จะมีหน้าต่าง **Create New Assistant** ให้กรอกชื่อบอท (**Display Name**) และรายละเอียด (**Description**)  
กรอกข้อมูลให้ครบแล้วกดปุ่ม **Create Assistant**

![หน้าต่างสร้างบอท (Create Assistant)](/images/Create_Assistant.png)

<br />

เมื่อสร้างบอทสำเร็จ ระบบจะแสดงหน้าต่างยืนยันการสร้างแชทบอท พร้อมตัวเลือกให้ผู้ใช้ดำเนินการต่อได้ 2 แบบ คือ

- **เอาไว้ก่อน** : ปิดหน้าต่างยืนยัน และกลับไปที่หน้า **Overview** เพื่อใช้งานภายหลัง
- **ตั้งค่าแชทบอท** : ไปยังหน้าต่าง **ตั้งค่าแชทบอท** ทันที เพื่อกำหนดค่า General / System / Documents ก่อนเริ่มใช้งาน

![หน้าต่างแจ้งสร้างบอทสำเร็จ](/images/CreateSuccessModal.png)

<br />

ในหน้ารายการบอท (Bot Cards) ผู้ใช้สามารถกด:
- ปุ่ม **เริ่มแชท**
- ไอคอน **ตั้งค่า** (ฟันเฟือง)
- ไอคอน **ลบ** (ถังขยะ)

![รายการบอท (Bot Cards)](/images/BotCards.png)

## การตั้งค่า Chatbot (Bot Settings)

หลังจากสร้างบอทแล้ว แนะนำให้ตั้งค่าบอทก่อนเริ่มใช้งาน โดยกดไอคอน **ตั้งค่า (ฟันเฟือง)** จากหน้า Overview  
ระบบจะแสดงหน้าต่าง **ตั้งค่าแชทบอท** ซึ่งประกอบด้วย 3 ส่วนหลัก:

- **1.General** 
- **2.System** 
- **3.Documents**

![หน้าต่างตั้งค่าบอท](/images/Bot_Settings_Modal.png)

---

### 1) General

ใช้สำหรับตั้งค่าทั่วไปของบอท เช่น:
- ชื่อบอท (**Display Name**)
- คำอธิบาย (**Description**)
- การแสดงผลบนหน้า **Explore**
- การแชร์บอทให้บุคคลภายนอก (ผ่านลิงก์)

![ตั้งค่า General](/images/Bot_Settings_Modal.png)

<Callout type="warning" title="สิทธิ์การแชร์บอท (สำคัญ)">
  การแชร์บอทไปหน้า <strong>Explore</strong> หรือแชร์ผ่าน <strong>ลิงก์</strong> ทำได้เฉพาะผู้ใช้ที่มีสิทธิ์ <strong>Staff</strong> เท่านั้น  
  และทุกครั้งที่กดเปิดการแชร์ จะต้องได้รับ <strong>การอนุมัติจาก Admin</strong> ก่อน จึงจะใช้งานได้จริง
</Callout>

---

### 2) System

ใช้กำหนด “พฤติกรรมการตอบ” ของบอท เช่น:
- **System Instructions (Prompt)** (ไม่บังคับ)
- **Creativity Level (Temperature)**
- **Recommended Questions** (คำถามแนะนำ) (ไม่บังคับ)

![ตั้งค่า System](/images/SettingsSystem.png)

ตัวอย่างส่วนของ System Instructions:
![ตัวอย่าง System Instructions](/images/System_Instructions.png)

ตัวอย่างส่วนของ Recommended Questions:
![ตัวอย่าง Recommended Questions](/images/Recommended_Questions.png)

<Callout type="default" title="คำแนะนำ">
  สำหรับบอทที่ตอบคำถามจากเอกสาร แนะนำตั้งค่า <strong>Temperature ต่ำ (เช่น 0.2 - 0.5)</strong> เพื่อให้คำตอบนิ่งและอ้างอิงจากเอกสารมากขึ้น
</Callout>

---

### 3) Documents (Knowledge Base)

ใช้สำหรับอัปโหลดเอกสาร PDF เพื่อให้บอทใช้ตอบคำถามจากเอกสารที่เพิ่มไว้ในระบบ

รองรับ:
- ไฟล์ **PDF**
- ขนาดไม่เกิน **10MB**
- ไม่เกิน **10 หน้า/ไฟล์** (ตามข้อจำกัดในหน้าอัปโหลด)

เริ่มต้นโดยไปที่แท็บ **Documents** แล้วคลิกพื้นที่อัปโหลดเพื่อเลือกไฟล์ PDF ที่ต้องการเพิ่มเข้าระบบ

![อัปโหลดเอกสาร (Documents)](/images/UploadKB1.png)

หลังจากเลือกไฟล์แล้ว ระบบจะแสดงไฟล์ในรายการอัปโหลด ผู้ใช้สามารถตรวจสอบชื่อไฟล์และขนาดไฟล์ ก่อนกดปุ่ม **เริ่มอัปโหลด**

![รายการอัปโหลดเอกสาร](/images/UploadKB2.png)

ระหว่างอัปโหลด ระบบจะแสดงสถานะ **กำลังประมวลผล** และไม่ควรปิดหน้าต่างในระหว่างดำเนินการ เพื่อป้องกันไฟล์อัปโหลดไม่สมบูรณ์

![กำลังประมวลผลเอกสาร](/images/UploadKB3.png)

เมื่ออัปโหลดเสร็จ ระบบจะแสดงสถานะสำเร็จ และเพิ่มไฟล์เข้าไปในส่วน **เอกสารในระบบ** ของบอทโดยอัตโนมัติ หากต้องการลบเอกสาร สามารถกดไอคอน **ถังขยะ** ในรายการเอกสารได้

![ลบเอกสารในระบบ](/images/UploadKB4.png)

<Callout type="default" title="ข้อควรรู้">
  ส่วน <strong>Documents</strong> เป็นการอัปโหลดแบบเรียลไทม์ จึงไม่จำเป็นต้องกดบันทึกเหมือนแท็บอื่น  
  แต่แท็บ <strong>General</strong> และ <strong>System</strong> ต้องกด <strong>บันทึก</strong> เพื่อให้ค่ามีผล
</Callout>

## หลังตั้งค่าเสร็จ: เริ่มแชทกับบอท

เมื่อบอทถูกตั้งค่าและมีเอกสารเรียบร้อยแล้ว ให้กลับไปที่หน้า Overview และกด **เริ่มแชท**  
หน้าแชทจะใช้สำหรับถามคำถามจากเอกสารที่อัปโหลดไว้

![หน้าแชท (ตัวอย่าง)](/images/Chat1.png)

หากตั้งค่า Recommended Questions ไว้ ผู้ใช้สามารถกดคำถามแนะนำเพื่อเริ่มใช้งานได้ทันที

![หน้าแชทพร้อมคำถามแนะนำ](/images/page_Chatrecomment.png)

## อื่น ๆ ที่ควรรู้ (FAQ แบบย่อ)

### จะลบ Chatbot ที่สร้างไว้อย่างไร?
ผู้ใช้สามารถลบบอทได้จากหน้า Overview โดยกดไอคอน **ถังขยะ** ที่การ์ดบอท หรือใน Sidebar (ถ้าระบบรองรับ)

### สามารถแชร์บอทให้บุคคลภายนอกได้ไหม?
ได้ **เฉพาะ Staff** และต้องได้รับ **อนุมัติจาก Admin ก่อน** ทุกครั้งที่เปิดแชร์ผ่านลิงก์

### สามารถนำบอทไปแสดงที่หน้า Explore ได้ไหม?
ได้ **เฉพาะ Staff** และต้องได้รับ **อนุมัติจาก Admin ก่อน** ทุกครั้งที่เปิดแสดงบนหน้า Explore

### จะใช้งานบอทของผู้อื่นได้อย่างไร?
สามารถเข้าไปที่หน้า **Explore** เพื่อค้นหาและเลือกบอทที่เปิดให้ใช้งานได้

![หน้า Explore](/images/page_Explore.png)

<Callout type="warning" title="คำเตือนด้านความปลอดภัย">
  ควรตรวจสอบสิทธิ์การเข้าถึงและความเหมาะสมของเอกสารก่อนเปิดแชร์บอททุกครั้ง  
  หลีกเลี่ยงการอัปโหลดเอกสารที่มีข้อมูลอ่อนไหวหรือข้อมูลภายในที่ไม่ควรเผยแพร่
</Callout>
