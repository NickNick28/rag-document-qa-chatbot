## สร้างบอทใหม่จากหน้า Overview

1. กดปุ่ม **สร้างบอทใหม่** หรือไอคอน **+**
2. ระบบจะเปิดหน้าต่าง Create New Assistant

![Create Assistant Modal](/images/Create_Assistant_Modal3.png)

> ✅ **ข้อกำหนดการสร้างบอท**
>
> - 1 ผู้ใช้สามารถสร้างบอทได้สูงสุด **2 บอท**  
> - หากสร้างครบแล้ว ให้ลบบอทที่ไม่ใช้งาน หรือแจ้ง Admin เพื่อพิจารณาเพิ่มสิทธิ์ตามความเหมาะสม


## อธิบายช่องกรอก

- **Display Name**: ชื่อบอทที่ผู้ใช้เห็นในระบบ
- **Description**: คำอธิบายสั้น ๆ ว่าบอทนี้ตอบเรื่องอะไร

ตัวอย่าง:
- Display Name: “บอทตอบค่าธรรมเนียมการศึกษา”
- Description: “ตอบคำถามจากเอกสารประกาศค่าธรรมเนียม ปีการศึกษา 2568”

## หลังสร้างเสร็จควรทำอะไรต่อ
หลังสร้างเสร็จ บอทยัง “ไม่มีความรู้” จนกว่าจะอัปโหลดเอกสาร  
ขั้นตอนถัดไปคือไปที่ **Settings** แล้วตั้งค่า System และ Documents

ดูต่อ: **การตั้งค่า System / Documents**
